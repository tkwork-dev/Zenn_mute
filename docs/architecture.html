システム概要

Zenn Mute User Alert は、Zennでミュートしたユーザーのページを開いた際に警告モーダルを表示するChrome拡張機能です。

    subgraph 同期フロー
        A[ユーザー操作] -->|同期ボタン押下| B[ミュート設定ページを開く]

    end
